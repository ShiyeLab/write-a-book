# 来源卡

每张卡只存一个连续摘录或明确事件。工具使用 JSON，字段对应见 [工具说明](../../docs/tools.md)。本表适合人工填写；未知写待确认，无关字段写不适用。

| 字段 | 填写要求 |
|---|---|
| id | 卡片稳定 ID，创建后不因排序改名 |
| source_id | 对应来源清单的唯一 ID |
| source_kind | external、author-sample、interview、teaching 等明确类别 |
| readiness | 待处理、可取材、待核；不与来源类别混用 |
| source_path／版本 | 相对来源清单的位置，普通文本校验值或版本号 |
| location | 连续句级编号、页码或时间戳；声明类型和核验方式 |
| quote | 完整摘录；由脚本提取或人工逐字核对，不用摘要顶替 |
| summary／tags | 单独的解释与分类，不修改 quote |
| attribution／basis | 说话人或作者，以及谁的哪份证据支持归属 |
| time／basis | 事件时间及依据；不能把记录日期当事件日期 |
| restrictions | 是否可公开、不可推断的结论、加工限制 |
| check | 机械结果、语义核对、待核点分别写 |

扫描进度可按来源记录“已覆盖位置／未覆盖位置／质量问题”。人物材料另记角色与同名歧义，避免由称呼推测真实身份。多个来源描述同一事件，保持原卡并在事件表连接。
