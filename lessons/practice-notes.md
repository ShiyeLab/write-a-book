# 从实践回到方法

以下经验按写作场景整理，列出问题、处理办法和检查方法。

| 场景 | 问题 | 做法 | 检查方法 | 适用范围 |
|---|---|---|---|---|
| 大量资料摘录 | 模型复述改变字句；后续分类节选又丢失尾部 | 选择位置后机械抽取；完整正文与摘要分开，分类只补元数据，缺 ID 失败 | 比较全文，另行核对底本 | 有稳定文本和位置的摘录链 |
| 双人访谈 | 字句完全一致，却被归给另一说话人 | 原话、说话人及归属依据分字段；跨源核对，未知留待核 | 机械核文本，人工核归属与上下文 | 口述、采访与日记成文 |
| 固定原著删节 | 删除操作没改字，指代和因果仍断裂 | 纯删节回放后另做接缝阅读；补写独立标记 | 机械保真与连贯审读各有结果 | 忠实缩写 |
| 存量稿润色 | 提取时漏表格或提示词，润色稿看似流畅完整 | 改前列信息清单并回对原件；逐项对应改后位置 | 对照原件检查结构与信息 | 工具书与含复杂块的说明稿 |
| 真实材料不足 | 为满足篇幅补动作或对话，改变真实性 | 保留缺口，补访或缩短；教学模拟显著标明 | 事实与作者核对，语言质量不能代替 | 真实经历写作 |
| 作者写法研究 | 堆标点和口头禅，看似相像却没有判断推进 | 先研究选择与论证，再查表面表达；规则附证据和反例 | 引文定位与小样审读；迁移另验 | 有可靠样本的写法研究 |

在自己的书中记录场景、问题、做法和效果；有共性时修改对应公共方法，并带回适用条件和失败原因，不能只写“效果很好”。见 [交流与改进](../README.md#交流与改进)。

## 资料处理与修订经验

| 场景 | 问题 | 做法与适用条件 |
|---|---|---|
| 混合文件提取 | 文字页有结果掩盖扫描页遗漏 | 逐页记录状态，覆盖与质量分开；引用前回原件 |
| 索引查缺口 | 没有卡片被说成原文没有 | 回查原件覆盖和近义表达，只报告已查范围 |
| 研究转写 | 相关被改成导致，检索记录代替出处 | 读研究方法和限制，正文反查来源，更新实际章节材料 |
| 全书统稿 | 各章通顺但术语冲突、前问无后答 | 对照章节职责、全书体例与未决项，记录阅读范围 |
| 作者反馈 | 复盘写了，下一任务仍读旧要求 | 已采纳才更新有效任务文件，注明替代关系；偏好不冒充统计 |

操作示范见 [贯通示例](../examples/getting-started/README.md)。
