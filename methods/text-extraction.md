# 从原始文件得到可核对文本

先登记输入、来源与版本，保留原件。TXT／Markdown 核编码、截断与范围后直接读，不必运行 OCR。其他载体选择下表所需路线，安装条件见 [可选工具](../docs/optional-tools.md)。

| 输入 | 处理 | 必须核对 |
|---|---|---|
| PDF 文字层 | 按页提取 | 页序、缺字、阅读顺序；文字少不等于空页 |
| 扫描页、图片、混合 PDF | 按页 OCR，可先试本地 Apple Vision | 逐页状态、数字人名、表格、跨页段落；空响应不能算成功 |
| DOCX | 顺序遍历正文段落与表格 | 修订读取口径、未处理公式的位置、嵌套表格、文本框、脚注、页眉页脚及图表文字的覆盖限制 |
| PPTX | 按幻灯片与形状提取文字、表格 | 图片、组合对象、备注等未处理对象 |
| XLSX／XLS | 工作表和单元格位置 | XLSX 公式与缓存值分别记录，日期、时间和时长保留类型；XLS 只提取保存值；图表图片不自动转文字 |
| 网页 | 当前工具取正文，或可选渲染采集 | 实际 URL、日期、获取状态和内容可用性分开 |
| EPUB／MOBI | 使用者准备外部转换工具，如 Calibre 导出文本后核对 | 本项目不内置通用转换器；核章节、脚注和丢失内容 |

直接提取或本地 OCR 足够时不升级服务。Apple Vision 仅适用 macOS；其他系统可输入已核对的 OCR 文本，或自行配置云端路线。难页再提高处理成本，不强制品牌、模型或双引擎。音视频转写由外部工具完成，本项目接收已核对文本。

## 处理记录与覆盖

每次生成到独立目录：文本、输入版本、方法与参数、页或对象清单、失败及疑点。PDF 物理页序从 1 开始，和纸面印刷页码分开；句级 L 编号指下一步处理底本的位置。摘录核验对照处理底本，OCR 质量核验对照原件。

没有正文的页也要留下记录，区分无文字待核、扫描待 OCR、失败和经原件确认的空白页。文字层和扫描混合时，部分页有文字不能让整份报告成功。长文逐页或小批处理，保留有效结果；续跑绑定原件校验值、页范围、引擎与参数，更换原件或参数需新目录。

Word 有待定修订时先明确读取原稿视图还是接受修改后的视图；未指定则停止该文件，不替作者接受修订。选择视图只控制提取，原件仍不修改。根据提取报告确认已覆盖和待补提的对象。已有表格、提示词块及图表文字要逐项对回原件，缺失项另行补提或登记未完成。

## 质量复核

用 [提取复核表](../templates/materials/extraction-review.md) 分别记录处理覆盖与质量结论：

1. 核总页数／对象数、已处理、失败、未处理和空白候选，不省略没有文字的页。
2. 在开头、中间、末尾及复杂位置选样，回看原件；记录具体页和对象，抽查不写全检。
3. 对准备实际引用的数字、人名、术语和关键句逐项核对；表格与脚注优先。
4. 可疑模式密度和关键词命中仅帮助找疑点。无人工参考转录不输出真实准确率；有参考也说明比较范围和分母。
5. 引擎一致仍可能同错；保留分歧，不能让另一个模型凭猜测“合成正确原文”。
6. 全页处理完成和质量复核通过分开；失败页未解决不得报告完整通过。

输出接 [来源登记与资料库](source-library.md)，再生成句级底本、请求和完整卡片。归属、日期和材料含义仍需阅读判断。
