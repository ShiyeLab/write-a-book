# 全书统稿与交付

输入为现行目录、各章稿件、brief 中的章节职责与体例、正文出处和未决项。已有精确大纲不重做策划；只改局部时只查受影响范围。规划从 [选题](book-planning.md) 和 [备料](preparation.md) 开始，各章通过不能直接相加成全书验收。

按 [统稿表](../templates/review/book-review.md) 定位问题并复查：

1. 目录、章数、章节任务是否兑现；前文提出的问题是否在指定位置回应，缺章和占位是否仍在。
2. 观点与案例在哪章展开，别章是必要回顾还是无意重复；跨章论断是否矛盾。调整须在本轮范围内。
3. 术语、译名、人物首次介绍、数字与标点是否按本书约定；这些不升为所有书的规则。
4. 全书和各章用同一篇幅口径，说明标题、脚注、标点是否计入；脚本字符数不能叫排版软件字数。缺材料应补证或调整任务，不堆同义句凑字数。
5. 正文论断与 [参考资料](../templates/materials/references.md) 是否对应；表格、引文、提示词、原有图表文字是否完整，编号与指向是否正确。
6. 待调研、待核出处、待补内容逐项解决或明确保留，不为“零待办”静默删除。

文件、数量和格式可以机械检查；重复、论证、承接和表达需要实际阅读，记录覆盖范围。三章短例见 [统稿示例](../examples/getting-started/book-review.md)。

按约定交付当前稿件、实际使用的参考资料、修改说明和未解决问题。给读者或编辑的稿件不夹带内部提示词、运行日志和过程批注。另需 Word 或 PDF 时说明实际转换与版面核验，本项目没有内置排版或一键出版。最终取舍由作者决定。
