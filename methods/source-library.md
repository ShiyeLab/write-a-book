# 来源库与逐字摘录

适用于需要回溯材料的资料写作、访谈整理与风格证据研究。输入是可使用的原件、来源说明、文本副本和本次取材问题。少量材料用来源表和卡片即可；资料较多、需要反复按主题取材时才建 Wiki。

1. 保存原件，给每份来源一个稳定 source_id。记录作者或讲述者、版本、源件路径、位置类型和使用限制。页码、音视频时间戳与句级编号各自有校验方法，不能互相冒充。普通文本可用 SHA-256 绑定版本；凭证不属于素材，不对其计算校验值。
2. 将抽取或 OCR 结果放入处理区。分别抽查标题、数字、人名、表格、跨页段落和疑难字，登记抽查范围。文字可搜索只说明已提取；OCR 正确需要回看图像或原件。提取路线见 [文本提取](text-extraction.md)，支持范围见 [可选工具](../docs/optional-tools.md)。
3. 句级工具先合并物理行、切句、编号。让取材者选择连续区间和卡片 ID，再由 `extract_quotes.py` 抓完整文字。卡片将 quote、summary、tags 分开；引文不能由摘要回填。改底本必须重新建立位置并核验。
4. 用 `verify_quotes.py` 重抽完整区间，检查来源版本、每一行和全文相等。脚本通过后再核归属、时间、语境和论点支持。说话人不明就写待确认，不能用主题推测身份。
5. 主题分类另存标签，通过稳定 ID 与卡片连接。`build_wiki.py` 只用完整卡片正文，主题和关键词只提供入口；每次生成到新目录，审查后再切换工作入口。已有相关条目必须有真实目标，不能因标题相近自动认定因果或矛盾。

产物为 [来源卡](../templates/materials/source-card.md)、来源版本清单、位置请求、完整摘录、校验结果及可选 Wiki。完成标准是每条素材能回到正确版本和位置，读者能辨认摘录与解释；空输入、缺来源、缺行、重复 ID 均需处理。查不到就保留缺口，不生成替代引文。完整演示见 [来源示例](../examples/source-based/README.md)。

## 从第一份材料开始，到修订维护

[来源登记](../templates/materials/source-register.md) 管原件、处理版本及未处理状态；`sources.json` 只收可供工具使用的带编号底本，校验值来自生成信息，不要求人工再抄一套。按需用 raw、materials/extracts、materials/lined、materials/wiki、drafts、reviews，不先建满所有目录。

| 操作 | 输入与动作 | 交给下一步 |
|---|---|---|
| 初次建立 | 清点稳定 ID、保护原件、提取复核、登记来源，按写作问题逐源阅读 | 位置请求、完整卡片、独立标签，按需生成索引 |
| 新资料 | 先核重复或新版；重复登记指向，不重复做卡；补充和冲突分别保留 | 新卡、受影响章节和待核问题 |
| 查找取用 | 主题入口 → 完整素材 → 原件上下文；精确引用由工具抽取并核验 | 有限制说明的章节材料包 |
| 修订维护 | 保留旧原件和底本；新版重新定位、列受影响卡片及正文引用；核验后更新 state | 现行版本入口，旧版退役说明 |

[阅读进度](../templates/materials/reading-progress.md) 按来源记总范围、已读范围、断点、已做卡、可用待补证、未采用理由。未采用不删除原件。转载和归属不明先标待核，不误归本人，也不一概删除有出处的二手资料。

**索引没有，不等于原件没有。** 卡片有选择地收录内容。要断言作者没说过，必须回相关原件查覆盖、别名与近义表达。原件未读全或提取不完整时，只能说“在已查范围未找到”。关键词无命中不证明语义不存在。示例展示 [原件有而卡片没有](../examples/getting-started/library-update.md)。

跨来源主题用既有 [材料包](../templates/materials/unit-pack.md) 和 [关系索引](../templates/materials/relations.md) 聚合。关键词相同只是查找线索；作者明写关系、编辑推测、待核冲突分别标注，推测不能冒充作者原意或因果。只给当前章节必要材料，不将全库一次塞进上下文；事实依据和文风范本分开。

有需要才建 [人物档案](../templates/materials/person-profile.md)：身份辨认、原话、时间、关系和不确定性，同名不自动合并。当前采用的判断与某原件曾怎样记载分开；新证据冲突时保留并复核，不因曾获确认而永久免检。少量可变事实在相关文件记现值、依据和变化，不引入企业库审批结构。

复用核心工具检查缺来源、重复 ID、错版本和关联目标；改动后检查链接及受影响的正文引用。工具不能核定语义关系或归属，不为适配旧结构检查器重建目录。
