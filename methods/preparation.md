# 按写作单元备料

适用于组织多个来源或多个章节，输入是 brief、当前结构、已掌握材料及其限制。来源卡按证据组织，素材包按要完成的写作任务组织，两者不要混成一张表。

先用一句话写出全书目标，再给每个章节写“回答的问题”和“不重复回答的问题”。把当前单元必须用、可以用、不能用的材料列入 [单元素材包](../templates/materials/unit-pack.md)，逐项附 ID、出处、位置和使用约束。例如，某记录只支持一次活动的流程问题，不能被扩成普遍效果。

将各单元摆在一起对照，用 [关系索引](../templates/materials/relations.md) 记录涉及的单元、关系种类、依据、呈现动作和答案位置。“都谈同一题”只作检索提示；深化、冲突或前文提问后文回答才改变写法。执行者可以在授权内作编辑判断，不能让关键词匹配替代语义判断。影响全书立场或未获授权的结构决定再提请确认。

准备深度由任务决定。固定原著的全书删节先了解全文结构和总预算，避免局部删掉后文需要的铺垫。真实经历只按已有材料组织，缺口列补访问题。一个局部润色任务只需核对该段及必要上下文。

产物是单元职责表、素材包、关系索引和缺口表。检查每条必须材料是否有来源，冲突是否写明处理，答案是否确实在目标单元。补材料后更新受影响单元与关系；只有新证据改变全书目标或框架时才重审全局。完整演示见 [材料包](../examples/source-based/unit-pack.md) 与 [关系小样](../examples/source-based/relations.md)。

每章的职责与预计篇幅在 [本书任务](../templates/book/brief.md) 中记录，研究结论通过来源 ID 进入材料包；全稿完成后按 [全书统稿](book-review.md) 核对，不用单章检查替代。
