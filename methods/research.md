# 找到资料，读懂并用于正文

输入是一个会影响选题、目录、论断或案例取舍的问题。先填 [研究计划](../templates/research/plan.md)：它服务哪项写作决定，需要寻找什么支持和反证，查到什么程度停止。只有一个能搜索的 AI 工具也能执行；本项目不替聊天工具增加联网能力。

## 按现有条件选择渠道

不规定使用哪几家 API，不限制路线总数：有一路就先用一路，已有十路也可以按问题选用。搜索工具、数据库、官网、访谈和用户提供的文件都可成为渠道；更多模型不等于更多独立证据。

开始时可提示：“目前可以使用【现有渠道】。如需扩大覆盖，可补充其他搜索 API、数据库或直接资料；也可以先用现有条件继续。”提示一次即可，不因没有其他服务反复询问或阻塞任务。

想从中文搜索入手时，可以优先尝试 DeepSeek 当前可用的搜索能力，再按需要补充豆包、千问、Kimi、百度等；这只是可调整的起点，不是质量排名，也不是必须同时调用的名单。模型名称在使用时按官方说明和自己的账号填写，通用方法不绑定某个版本。路线顺序、数量和并发由使用者结合问题、预算及服务限制选择；本地脚本支持显式配置，详见 [可选工具](../docs/optional-tools.md)。

## 从问题到直接来源

问题 → 支持与反证问题 → 渠道选择 → 线索 → 打开直接来源 → 核原文 → 记录证据和未知 → 更新章节任务。

根据问题补充检索角度、渠道和来源。AI 回答、搜索摘要只提供线索。重要事实回到页面或文件，核主体、作者或机构、日期、上下文、数值单位与适用范围。没有原件就标待核，不能用模型记忆补全。网页抓取成功也可能只是登录页或验证码；内容无效不入证据正文。

相反证据一起保存。多个网址或多个模型转引同一报告只算一个原始来源；先查原始发布者和原文位置，再判断独立性。冲突数字不平均，模型票数不裁决事实。官网可证明某方公开说过什么，不自动证明效果或需求。某一路没运行只说明它未覆盖哪些问题，不据此否定其他独立来源。

[证据表](../templates/research/evidence.csv) 用问题编号和来源 ID 连接来源卡。记录支持或反对、直接链接或文件位置、发表和访问日期、摘录或概述、原件检查、独立性、限制和引用状态。访问日期只写实际发生的时间；模拟记录明确写模拟。供应商运行信息留在运行记录，不扩成日常写作表。

问题得到足够支持、连续检索没有新增实质信息，或后续只能靠访谈、实验及作者判断时停止扩搜。写明实际搜索范围、失败渠道和未解问题，选择补查、收窄结论或保留未知。

## 解读证据

重要论文或研究用 [研究笔记](../templates/materials/research-note.md) 读到对象、样本与情境、方法、结果、局限。只读摘要就写未读全文；日常事实无需填论文专用字段。分别写原文直接报告什么、研究者怎样解释、书中准备怎样表达。

横断面的相关关系不能改成因果；特定人群和情境不能直接推广到所有读者；单篇研究不能代表共识。保留不一致结果，说明证据支持到哪一步。逐字引用核文字和位置，转述还要核意义与范围。示例见 [贯通示例](../examples/getting-started/README.md)。

## 让研究进入写作

每项影响写作的发现记录采用、暂缓或不采用及理由，更新下一任务实际读取的 brief、章节材料或待核问题。沿来源 ID 取正文，不在多个表中重复粘贴整篇摘录。形成当前任务后接 [备料](preparation.md)；长期积累接 [资料库](source-library.md)。只写研究报告而下一任务仍读旧要求，不算完成。

## 从正文反查参考资料

用 [参考资料模板](../templates/materials/references.md) 区分逐字引文、转述观点与背景阅读。逐句检查重要论断能否找到来源，条目是否真的在正文使用。按来源类型记录作者、标题、出版或发布信息、年份、必要页码及链接，格式服从本书或出版方要求。经典也要核版本和位置；短引用也保留可追溯记录。二手转述明确注明，缺作者、页码或日期就待核，不补造。背景书目可以单列，不冒充已实际引用。

## 可选检索命令

[可选工具](../docs/optional-tools.md) 提供多路接口的归一化和原生搜索记录导入。帮助、预检和教学回放不请求服务；真实调用须明确选路线并启用网络。宿主工具的搜索通过记录导入；检索线索经原件复核后进入写作证据。
