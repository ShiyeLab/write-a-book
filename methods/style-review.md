# 文风审读

适用于已经形成文字、需要改善可读性的任务。输入为稿件、文体、作者要求或编辑要求，以及可选规则文件。先确认加工边界：引文保真和纯删节的限制优先于一般措辞偏好。

先运行 `scan_style.py`，它只按规则定位并生成建议。默认规则是少量可修改的编辑偏好；局部禁词应在单书规则文件中另列。命中后结合上下文决定是否修改。没有可靠作者样本与明确统计方法时，不输出密度阈值或作者相似度。

扫描默认跳过 Markdown 引用行，始终跳过围栏代码块；其他忠实引文需使用 `<!-- style:off -->` 和 `<!-- style:on -->` 包围。普通正文里的引号不会被自动识别为可靠引用，必须明确标注。报告列位置和规则，执行者逐项决定保留、修改或不适用。

再做语义审读：句子是否回答读者的问题，段落有无推进，例子能否支撑判断，情绪与结尾是否由内容产生。将“我偏好更短”与“读者无法理解因果”分开。前者通常是建议，后者可能影响核心交付。风格规则自身有问题时先收窄规则，不逼正文凑公式。

产物是扫描报告、带位置的审读意见和已授权的修订稿。修改后复核意思、数字、引文及必要的信息项，记录误报与保留理由。扫描不自动改稿，不生成 AI 率。完整演示见 [润色示例](../examples/polishing/README.md)。

## 阅读时逐项判断

使用 [语义清单](../templates/review/style-checklist.md) 记录位置、依据、具体动作与复查。先补信息和论证，再处理重复与结构，最后修词句。没有来源的细节宁可保留缺口，不能编亲历或情绪使文字“像人写”。

导览预告、空泛赞叹、拟人化论战、工作过程外露都要结合体裁：技术书讲工作方法可用相应术语，真实作者的标点偏好也不一律禁止。规则只是提示。正则不能判断假共情或论证深度；当前扫描器没有段落密度或相邻段落模式判断，不作此承诺。六组改写与两组保留反例见 [新写对照](../examples/getting-started/style-review.md)。
