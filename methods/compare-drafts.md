# 比较同题候选稿

适用于同一任务已有两个或更多候选，或者希望检查不同写法的适用性。输入必须记录任务版本、素材范围、风格要求、篇幅口径和候选来源；不同任务的稿件不能直接据此排模型优劣。

先建立共同标准：是否回答本单元问题、事实与引用是否有依据、段落推进是否清楚、章间职责是否重复、读者是否能理解。事实硬错误不能被语言流畅的分数抵消。可用通过／问题／待核，也可按事先约定评分，不能读完以后为偏爱的候选改标准。

给候选稳定标签，记录实际输入和生成信息。人工示范稿写“随仓库提供的示范输出”；模型信息不明写未知，没有运行数据时不编调用次数、耗时和成本。比较篇幅需用同一口径，例如基本汉字区间计数与含标点字符数不能混比。

逐项引用稿件位置解释选择。可以选择一稿再局部修订，也可以全部淘汰。合并时重新审读，不能假设两份各自通过的段落拼起来也通过。保留没有选用的稿件及原因，现行 state 只指向采用版本。

产物是候选、共同任务、比较表、选择理由及改后稿。比较结论注明任务、共同输入和取舍依据。完整演示见 [两稿选择](../examples/source-based/comparison.md)。
