# 新写文风对照

以下对照为教学编写，改后事实取自本例材料。前六组由阅读发现语义问题，后两组说明不应机械修改。

| 类型 | 改前 | 改后／保留 | 理由及条件 |
|---|---|---|---|
| 空话 | 小小的登记表承载着无限可能，推动交换体验全面跃升。 | 表里记录名称和数量，登记结束后核对批次。 | 回到材料中的字段与动作，不新增效果 |
| 重复 | 数量必须写清，清楚的数量不可缺少，不能没有数量。 | 写清数量。 | 三句没有新增信息，保留一项要求 |
| 假共情 | 你一定因为种子盒太多而焦虑，但你的不安值得被温柔接住。 | 找盒子前先看批次编号。 | 没有情绪依据，不替读者宣布焦虑；用已有操作回答问题 |
| 强行拔高 | 放好纸袋，就是为社区文明种下永不枯萎的希望。 | 多余纸袋放在南侧抽屉。 | 去掉无依据意义，保留可核位置 |
| 预告腔 | 接下来我们将隆重介绍一个重要环节，那就是核对。 | 登记结束后核对批次。 | 不是导航任务，不需再播报标题 |
| 机械结构 | 这张表既是纽带，也是桥梁，更是灯塔。 | 表里填写种子名称和数量。 | 对称比喻没推进解释；不硬凑三项 |
| 不宜改：引文 | 原记录：“我想先看批次标签。” | 原样保留，归属仍标待核。 | 逐字引文不因编辑偏好改词，也不擅加说话人 |
| 不宜改：有依据的情绪 | 教学访谈设定已明写：“找回那包种子后，我松了口气。” | 保留并标为教学设定，不能挪作真实亲历。 | 情绪有明确文本依据，不应一概删掉 |
