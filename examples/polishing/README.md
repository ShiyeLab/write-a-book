# 保留信息的局部润色

材料性质：原创的纸样管理说明，人物案例是教学虚构，包含数字、表格、编号步骤、提示词和图示文字。

## 使用步骤

1. 读 [原稿](original.md) 和 [编辑反馈](feedback.md)，确认只改首段。
2. 按 [任务](task.md) 独立润色，逐项对照 [保全清单](preservation.md)。
3. 阅读随仓库提供的 [修订稿](revised.md) 与 [修改记录](changes.md)。
4. 运行示例检查未修改范围，生成文风建议和保全报告，再阅读首段判断意思是否保持。

## 运行示例

在仓库根目录运行；输出目录须为新路径：

```sh
run=$(mktemp -d)
python3 examples/replay.py polishing --output "$run/polishing"
```

示范稿供阅读比较，回放命令执行本地工具和范围检查。已有检查结果在 [generated](generated/)，逐个工具命令和格式见 [工具说明](../../docs/tools.md)。

自动检查：首段以外完全相同；指定字面信息存在；扫描不改变输入。

仍需阅读判断：首段拆句是否清楚、比喻和案例含义是否保留。

练习写新稿时，将 task.md 交给所用的 AI 工具，产物保存在自己的书里，再按此例检查。
