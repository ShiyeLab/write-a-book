# 给纸样编一张查找卡

桌边积攒了12张包装纸样以后，周栩想找回蓝色条纹的那一张，他先翻了全部纸样，这件事说明查找的时候光凭记忆其实不太方便，所以可以给每张纸样准备一张卡，编号像地址一样帮助找到位置。

编号从01开始，同一张纸样只用一个编号。下面的记录是教学样例，不表示真实收藏。

| 编号 | 图案 | 存放位置 |
|---|---|---|
| 01 | 蓝色条纹 | A袋 |
| 02 | 灰色圆点 | B袋 |

1. 给纸样背面写编号。
2. 在卡片上记录图案和存放位置。
3. 把卡片放在目录盒里，再按卡找一次纸样。

提示词可以这样写：

```text
请把下面的纸样记录整理成表格。
只保留编号、图案、存放位置三列。
未知位置写“待确认”，不要根据图案猜测。
记录：01，蓝色条纹，A袋；02，灰色圆点，B袋。
```

图示文字：纸样编号 → 查找卡 → 存放袋。纸样换袋后，卡片位置也要同步更新。
