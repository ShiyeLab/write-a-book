# 双人访谈成文

材料性质：人物、对话和事件全部为原创的虚构教学访谈；没有真实录音。

## 使用步骤

1. 读 [a 底本](raw/a.txt)、[b 底本](raw/b.txt)，注意未辨认说话人片段。
2. 运行示例抽取六条摘录并核对原话；查看 [卡片](generated/cards.json)。
3. 读 [事件归并](events.md)、[缺口表](gaps.md)，比较两人的记忆和归属依据。
4. 读 [工作稿](draft.md) 与 [审读](review.md)，查看待补标记怎样保留。
5. 用 [任务](task.md) 在自己的工作区写新稿并做归属审读。

## 运行示例

在仓库根目录运行；输出目录须为新路径：

```sh
run=$(mktemp -d)
python3 examples/replay.py true-stories --output "$run/true-stories"
```

示范稿供阅读比较，回放命令执行本地工具和范围检查。已有检查结果在 [generated](generated/)，逐个工具命令和格式见 [工具说明](../../docs/tools.md)。

自动检查：六条完整摘录可与底本对应。

仍需阅读判断：说话人归属、跨源是否真是同一事件、哪些细节需要作者确认。

练习写新稿时，将 task.md 交给所用的 AI 工具，产物保存在自己的书里，再按此例检查。
