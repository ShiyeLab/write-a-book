本项目是一套利用大语言模型（LLM）创作图书的方法与工具集，内容涵盖选题策划、资料调研、文本提取、资料库建立、正文撰写、修改与全书审读等环节。项目提供相应的方法说明、模板、本地工具和教学示例，使用者可以根据自己的题材、读者和写作目的选择使用。

项目内容整理自图书写作实践，教学材料另行编写。

## 主要内容

- **明确写什么**：[选题策划](methods/book-planning.md)，说明读者起点、要回答的问题、材料条件和章节分工。
- **找资料并读懂**：[资料研究](methods/research.md)，寻找支持与反证，核对研究的适用范围，让正文论断对应实际出处。
- **提取与整理**：[文本提取](methods/text-extraction.md)和[资料库](methods/source-library.md)，处理原始文件，检查覆盖，保存来源与版本，持续补充资料。
- **备料和写作**：[写作准备](methods/preparation.md)，组织章节材料、原话、未知和篇幅要求，按下列四类任务写作。
- **修改与全书审读**：[文风审读](methods/style-review.md)、[修订](methods/revision.md)和[统稿](methods/book-review.md)，检查信息完整性、论证、跨章重复、术语与出处。
- **记录有效经验**：[作者写法](methods/author-style.md)和[实践记录](lessons/practice-notes.md)，让已采纳反馈进入下一任务，退役不再适用的旧要求。

项目提供四类写作示例和一套[从原始资料开始的教学示例](examples/getting-started/README.md)。

## 快速开始

1. Fork 或下载项目。
2. 在能够读取本地文件的 AI 工具中打开项目；只能聊天时，提供 [执行说明](AGENTS.md)及当前任务相关文件。
3. 说明主题、读者、已有材料和想先做的一步，可以复制下面的请求。
4. 由 AI 根据模板建立本书目录与要求，先完成资料清点、目录草案或样章中的一项小任务。
5. 查看产物和检查结果，确定后继续；下次从本书的 `state.md` 接续。

> 请先阅读 AGENTS.md 和使用说明。我想写一本关于【主题】、面向【读者】的书，已有【想法、材料或稿件位置】。请先做【资料清点／目录草案／一个样章任务】，建立本书要求和来源记录；未知不要补造，暂时不要写全文。把进度、待核问题和下一步读取的文件写入本书状态。

三种起点和手动建目录的步骤见[使用说明](docs/getting-started.md)。AI 能否读取文件、联网和运行命令取决于所用工具；缺某项能力时，先完成能独立进行的步骤并说明缺项。

阅读方法和使用模板无需安装程序。八个核心文本工具只需 Python 3.9 或更新版本及标准库；文档提取、OCR、网页采集和外部搜索按需准备依赖或账号，见[可选工具](docs/optional-tools.md)。搜索渠道和模型由使用者选择，不要求开通固定数量的 API。

自己的图书资料和稿件默认由 `.gitignore` 排除在 Git 提交之外。需要公开时，再检查并调整实际提交范围。

## 适用任务

| 写作任务 | 流程要点 | 说明与示例 |
|---|---|---|
| 根据资料撰写章节 | 整理来源与摘录，准备章节材料，核对论点与依据 | [流程](workflows/source-based.md) · [示例](examples/source-based/README.md) |
| 整理采访、口述与真实经历 | 核对说话人、事件和原话，记录材料缺口，组织叙述 | [流程](workflows/true-stories.md) · [示例](examples/true-stories/README.md) |
| 在保留原句的前提下缩写 | 按计划删节，检查篇幅与上下文衔接，单独标明补写 | [流程](workflows/abridgement.md) · [示例](examples/abridgement/README.md) |
| 修改和润色已有稿件 | 列出必须保留的信息，修改表达，核对遗漏与含义变化 | [流程](workflows/polishing.md) · [示例](examples/polishing/README.md) |

目前尚未形成经过完整实践验证的小说写作流程，因此本项目暂不提供小说创作流程及配套示例。

四类写作示例包含任务说明、教学材料、示范稿件及检查记录。示范稿件供阅读和比较；运行示例命令会执行本地处理与检查。

## 方法如何组织

项目将通用方法与具体图书的要求分别记录，按实际任务选择和组合。

- **通用方法**：说明资料如何整理和核对，写作任务如何准备，稿件如何审读和修改。
- **具体要求**：每本书单独记录读者、写作目的、体裁、篇幅、文风及允许的修改范围，保留当前稿件与进度。
- **实践改进**：记录使用中的问题、处理办法和适用条件，将具有共性的经验补充到通用方法中。

同一会话可以按步骤完成工作，也可以按需要分工。作者负责确定写作目标与最终取舍，LLM 依照任务要求参与写作和审读，本地工具承担文本抽取、比对与定位等可重复检查。具体约定见[写作原则](docs/principles.md)。

核心工具处理文本和结构化数据；可选工具提供 PDF、DOCX、PPTX、XLSX、XLS 提取及逐页 OCR，并报告未覆盖对象。提取结果需对原件核对后再入库。文本核验检查摘录、位置和指定内容；事实、论证与表达结合原始材料审读。
