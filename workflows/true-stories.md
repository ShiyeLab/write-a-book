# 真实经历成文

从已有口述、采访、日记或作者稿开始。准备来源、版本、说话人清单及成文授权；先用 [来源方法](../methods/source-library.md) 保留原话，再考虑如何组织叙事。

对话底本保留说话人、时间位置和听不清处。文字逐字相同与说话人归属是两次检查。将多个来源讲述的同一事件合并到事件表，分列一致部分、互补细节、冲突与缺口；不能把两个人的“我”合成一个人的亲历。采访者复述也不自动算被访者原话。

按作者声音组织工作稿。事件顺序可以在授权内调整，事实、人物动作与对话必须有材料依据。缺少细节就保留待补处，列可回答的补访问题；篇幅目标不能成为编造的理由。模拟试写需单独授权并显著标明，不能混入已确认经历。

交付工作稿、引用对应、事件归并、缺口和作者核对项。归属不明不写成确定人物原话；冲突未解决不冒称事实审读通过。作者核实和采用需有实际记录。完整教学示例见 [双人访谈](../examples/true-stories/README.md)，其中所有人物与事件均为新写虚构材料。
