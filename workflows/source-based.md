# 资料驱动写作

从读者问题和资料范围开始。准备 brief、可回溯来源及当前章节职责，采用 [来源方法](../methods/source-library.md) 和 [备料方法](../methods/preparation.md)。

先将资料拆成来源卡，再做“论点—素材—限制”对应。区分有直接依据、只能推断和当前缺口；研究结论或竞争作品的形式不能替你决定本书定位。材料多时按主题取材，材料少时直接查卡。给每章明确职责，重复话题要说明是新角度、深化还是无谓重复。

把一个单元的材料、关系和写法要求交给写手，稿内或另表标出取材 ID。写后先核引文，再核论点是否被材料支持。出现无源新事实时补来源或收窄表述，不能靠流畅解释补足证据。按 [修订方法](../methods/revision.md) 处理审读意见，必要时按 [候选比较](../methods/compare-drafts.md) 选择。

交付单元稿、来源对应、剩余缺口、审读及改动记录。完成意味着任务范围内的产物可核查，作者是否定稿另按 brief。完整示例与执行任务见 [来源示例](../examples/source-based/README.md)。
